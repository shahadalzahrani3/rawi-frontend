# Rawi (راوي)

## Project Description

Rawi is a web platform that connects authors with narrators to turn written books into audiobooks.

Authors can upload their books and review narrator auditions, while narrators can browse available projects, submit voice samples, and manage their work. Administrators can manage users and monitor platform activities.

This project was developed as part of SWE363 – Web Engineering, Phase 4 (Front-End Implementation).

## Team Members

- Shahad Alzahrani – Homepage, Login, Registration, and Navigation
- Fatema Algadihi – Author Pages
- Norah Aljammaz – Narrator Pages
- Raghad Murayh – Admin Pages

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- React Router

## Installation and Running Instructions

1. Clone the repository:

   ```bash
   git clone https://github.com/shahadalzahrani3/rawi-frontend.git
   ```

2. Open the project folder:

   ```bash
   cd rawi-frontend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal, usually:

   http://localhost:5173/

## Main Features

### Homepage
- Introduction to the Rawi platform
- Navigation between pages
- Links to login and registration

### Authentication
- User registration
- Login
- Account activation
- Password recovery
- Navigation to dashboards based on user roles

### Author
- Author Dashboard
- View and manage books
- Upload books
- Review narrator auditions
- Manage author profile

### Narrator
- Narrator Dashboard
- Manage narrator profile
- Upload and manage voice samples
- Browse available projects
- View project details
- Submit and manage auditions
- Track current projects
- View payments

### Admin
- Admin Dashboard
- Manage users
- Manage platform content
- Monitor platform activities

## User Roles

The platform includes the following roles:

1. Author – Uploads books and manages audiobook projects.
2. Narrator – Browses projects, submits auditions, and manages narration work.
3. Admin – Manages users and platform activities.

## Website Design

The frontend was developed using React and CSS, following the team's medium-fidelity Figma wireframes.

The website includes:
- Arabic interface
- Consistent colors and typography
- Navigation between pages
- Organized dashboards for different user roles
- Responsive page layouts

## Current Limitations

This milestone focuses on frontend development.

- Some features use demonstration data.
- Full backend and database integration are outside the scope of this milestone.
- Real payment processing is not implemented.
